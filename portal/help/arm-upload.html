Что загрузить

Исходный файл от линии (.xlsx). На странице впишите то, чего в нём нет: дату прихода, даты коносаментов, терминалы и коды портов для имён файлов. Настройки задаются отдельно для каждой пары портов погрузки и доставки.

Что получится

По файлу на каждую пару портов погрузки и доставки (PlaceOfReceipt + PlaceOfDelivery) с именем «for ARM uploading <судно> <рейс>_<код выгрузки>_<код погрузки>.xlsx» в формате для АРМ: названия портов и терминалов, пломбы через запятую, класс опасности и UN одной графой. Дата коносамента и терминал выгрузки задаются отдельно для каждой пары. Скачать можно всё архивом .zip или по одному.

На что обратить внимание

  • Данные переносятся как есть: ошибки исходного файла попадут и в файлы для АРМ. Сначала прогоните его через «Проверить исходный файл линии».
  • Для знакомых портов (Nansha, Alexandria, Istanbul) название и терминал подставятся сами; для нового порта их нужно вписать вручную.
  • Включите «Формировать файлы с незаполненными данными», если какие-то данные неизвестны. Пустые ячейки этих данных будут выделены жёлтым; коды портов для имён файлов всё равно обязательны.
  • У контейнера, который стоит в нескольких строках, вес тары пишется только в первой — в остальных 0.
  • Введённые даты запоминаются для этого судна и рейса — при повторной загрузке вписывать их заново не нужно.
