Что загрузить

Исходный файл от линии (.xlsx). На странице впишите то, чего в нём нет: дату прихода, дату коносамента для каждого порта погрузки, терминал выгрузки (по умолчанию Timber Port) и код порта выгрузки для имени файла (обычно RUPLP).

Что получится

По файлу на каждый порт погрузки (PlaceOfReceipt) с именем «for ARM uploading <судно> <рейс>_<код выгрузки>_<код погрузки>.xlsx» в формате для АРМ: названия портов и терминалов, пломбы через запятую, класс опасности и UN одной графой. Скачать можно всё архивом .zip или по одному.

На что обратить внимание

  • Данные переносятся как есть: ошибки исходного файла попадут и в файлы для АРМ. Сначала прогоните его через «Проверить исходный файл линии».
  • Для знакомых портов (Nansha, Alexandria, Istanbul) название и терминал подставятся сами; для нового порта их нужно вписать вручную.
  • У контейнера, который стоит в нескольких строках, вес тары пишется только в первой — в остальных 0.
  • Введённые даты запоминаются для этого судна и рейса — при повторной загрузке вписывать их заново не нужно.

Примеры файлов

  • ishodnyj-fajl-linii.xlsx — исходный файл с двумя портами погрузки (Nansha и Istanbul): получится два файла
