# Что уже построено

Читается исполнителем до начала работы. Не изобретай заново то, что здесь есть.

## Границы, решённые в спецификации

Один узел: главная страница (`index.html` + `tools.js`). Ни новых модулей, ни сети —
разбивка на швы не нужна (T0).

- `tools.js` — единственное место для поля `category: 'export' | 'import'` у каждого
  инструмента (как и раньше для добавления нового инструмента — CLAUDE.md).
- `index.html` — рендерит два отдельных `.tool-grid` (по одному на категорию),
  переключает видимость через `[hidden]` на самом гриде, не на карточках —
  так у каждой вкладки свой независимый счёт CSS-counter'а (`.tool-card::before`
  в `assets/style.css`).
- По умолчанию открыта вкладка «Экспорт».

## Построено (T0, единственный проход)

Ровно по границам выше: `tools.js` — поле `category: 'export' | 'import'` у каждого
из 7 инструментов (export: `merge/`, `order-check/`; import: остальные 5);
`index.html` — два `<button role="tab">` + два `.tool-grid[role=tabpanel]`
(`tool-grid-export`, `tool-grid-import`), переключение через `.hidden`-свойство
на гриде; `assets/style.css` — `.tabs`/`.tab`/`.tab--active` и правило
`.tool-grid[hidden] { display: none; }` (без него `[hidden]` проигрывает
каскаду обычному `.tool-grid { display: grid }`, т.к. оба правила авторские
с одинаковым источником). Проверено вручную в браузере: обе вкладки, состав
карточек, независимая нумерация 01.. в каждой.

## Общие правила проекта

- Статический сайт, ES-модулей в `index.html`/`tools.js` нет и не должно быть
  (страница открывается напрямую двойным кликом, `file://`).
- Тесты: `npm test` (node --test, 82 теста в текущих модулях) — эта правка не
  трогает ни один из протестированных модулей (`lib/`, `merge/`, `dg-check/`,
  `dashboard/`, `dashboard-departure/`, `bl-split/`, `grand-total/`, `order-check/`),
  так что набор тестов не растёт; после правки прогнать `npm test`, ожидать
  82 passed, 0 failed, как было.
- Кэш-версия: правится `tools.js` — обновить `?v=` у `<script src="tools.js?v=...">`
  в `index.html` (CLAUDE.md, «Подводные камни»).
- Не трогать: любые файлы внутри `merge/`, `dg-check/`, `dashboard/`,
  `dashboard-departure/`, `bl-split/`, `grand-total/`, `order-check/`, `lib/`.
