# Спецификация: Вкладки «Экспорт»/«Импорт» на главной

## Задача

Инструментов на сайте уже семь, и все они лежат одним общим списком на
главной странице. Часть инструментов относится к оформлению экспорта
(вывоза груза), часть — к импорту (ввозу); в одном общем списке это не
видно, и найти нужный инструмент по смыслу, а не по названию, сложнее,
чем могло бы быть.

## Решение

На главной странице появляются две вкладки-переключателя над списком
инструментов: «Экспорт» и «Импорт». По умолчанию открыта «Экспорт».
Каждый инструмент относится ровно к одной вкладке; переключение вкладки
меняет только то, какие карточки видны — сами карточки, их вид и ссылки
не меняются.

Во вкладку «Экспорт» переезжают два инструмента, которые сегодня стоят
в общем списке первым и седьмым (последним): «Объединить манифесты» и
«Сверить с поручениями на погрузку». Остальные пять инструментов — в
«Импорт»: «Сверить опасные грузы», «Дашборд по портам назначения»,
«Дашборд по портам отправления», «Разделить коносаменты», «Итоговый
PDF-отчёт по манифесту».

## Решения по реализации

- **Категория — поле данных, не отдельный список.** В `tools.js` у каждого элемента `window.TOOLS` появляется `category: 'export' | 'import'` — единственное место правки при следующем перекладывании инструмента между вкладками, как и раньше для добавления нового инструмента (CLAUDE.md уже называет `tools.js` единственным местом для этого).
- **Номер на карточке (`counter-increment` в `assets/style.css`, `.tool-card::before`) считается заново в каждой вкладке**, не сквозным по всем семи инструментам. Причина: счётчик — это визуальный номер карточки в её списке, а не идентификатор инструмента; после разбивки на две вкладки счёт «1, 2, 3…» внутри каждой вкладки понятнее, чем «1, 2, 7» на «Экспорте». Слова брифа «инструмент 1 и 7» относятся к сегодняшнему единому списку и однозначно определяют, какие два инструмента переносятся (R07i) — на итоговый вид карточек это не влияет.
- **Два отдельных грида, не один с фильтрацией через `[hidden]` на карточках.** Один `#tool-grid-export` и один `#tool-grid-import`, рендерятся оба сразу при загрузке; переключение вкладки показывает один и прячет другой через `[hidden]` на самом гриде. Это и даёт независимый счёт CSS-counter'а по вкладкам (см. выше — `display: none`/`[hidden]` исключает элемент из подсчёта счётчиков), и не требует перерисовки карточек при клике.
- **Активная вкладка — обычный клик по кнопке**, без адреса/хэша в URL и без сохранения выбора между визитами: бриф не просил ни того, ни другого, а сайт — статические html-страницы без роутинга.
- **Кэш-версия.** Правится `tools.js` и `index.html` — по правилу CLAUDE.md о `?v=` бампается ссылка `tools.js?v=...` в `index.html`.

## Границы и швы

Один узел: главная страница (`index.html` + `tools.js`), правки внутри двух файлов, без новых модулей и без сети. Ручной smoke-тест в браузере — единственный шов (автотестов на статический рендер главной страницы на сайте нет и не заводится специально под эту правку).
