# 03 — Инструмент «Сверить опасные грузы»

**Требования:** R12, R12.1, R12.2, R13, R14, R15i, R16i, R16i.1, R17i
**Blocked by:** 01
**Зона:** `dg-check/`
**Волна:** 2
**Status:** ready

## Что должно заработать

Жена заходит на `dg-check/index.html`, загружает два файла в два отдельных слота —
«Сводный файл» и «DG-манифест». Кнопка «Сверить» неактивна, пока не загружены оба.

По нажатию: в обоих файлах по тексту заголовка (без учёта регистра) ищутся нужные
колонки — номер контейнера в обоих файлах, «Опасные грузы» в сводном, UN-номер и
класс в DG-манифесте. Если какой-то заголовок не найден — понятная ошибка с
указанием, какой именно заголовок и в каком файле не нашёлся.

Если всё найдено — для каждого контейнера из DG-манифеста собирается строка вида
`IMO <класс> UN <номер>`, при нескольких позициях на контейнер — через « / », в
порядке появления строк в DG-манифесте. Эта строка попадает в новый столбец
«Опасные грузы (сверка с DG-манифестом)» в конце сводного файла, для каждой строки
сводного файла с совпавшим номером контейнера. Если текст в новом столбце не
совпадает с уже имевшимся столбцом «Опасные грузы» — вся строка (от первой до
последней колонки, включая новый столбец) закрашивается жёлтым. Строки, где нет
данных об опасном грузе ни в сводном файле, ни в DG-манифесте, не трогаются —
без заливки, новый столбец пуст.

Если контейнер встретился в DG-манифесте, но не нашёлся в сводном файле — новых
строк не создаётся, а в сводке результата отдельной строкой указывается, сколько
таких контейнеров не нашли.

После сверки на странице видна сводка (число расхождений, число ненайденных
контейнеров) и кнопка «Скачать», отдающая результат как `.xlsx` с сохранённым
форматированием и подсветкой.

## Из брифа, дословно

> «В этом файле содержится информация о классе опасности грузов. Столбец M класс в
> столбце J UN. Необходимо сравнить информацию в данном файле с информацией по
> опасным грузам из ранее полученного собраного сводного файла. Сделай новый
> столбец в сводном файле. Если найдешь различия, то выдели желтым цветом строки»
> «Добавил столбец Z «Опасные грузы (сверка с DG-манифестом)» — туда попали
> официальные UN-номер и класс по каждому контейнеру ... сопоставление шло по
> номеру контейнера»
> «эти строки закрашены жёлтым по всей ширине таблицы (C:Z)»
> «Строки, где данных об опасном грузе нет ни там, ни там (892 строки) — не трогал»
> IMO 9 UN 3267 / IMO 8 UN 3077 — формат нескольких позиций на контейнер

## Разделы спецификации

Истории 11–17; Решения по реализации (сопоставление колонок по заголовку,
сопоставление строк по номеру контейнера); Границы и швы (`dg-check/core.js`).

## Критерии приёмки

- [ ] Кнопка «Сверить» задизейблена, пока не загружены оба файла
- [ ] Отсутствие нужного заголовка (например, переименовали колонку) даёт явную
      ошибку с указанием заголовка и файла, без падения и без тихого пропуска
- [ ] Новый столбец «Опасные грузы (сверка с DG-манифестом)» появляется в конце
      таблицы с верным текстом для контейнеров с одной и с несколькими позициями
- [ ] Строки с расхождением между старым и новым столбцом закрашены жёлтым по всей
      ширине таблицы; совпадающие и пустые с обеих сторон — не тронуты
- [ ] Контейнер, есть в DG-манифесте, но не в сводном файле — не создаёт новую
      строку, а попадает в сводку («не найдено: N»)
- [ ] После сверки видна сводка результатов на странице
- [ ] Кнопка «Скачать» отдаёт `.xlsx` с сохранённым форматированием и подсветкой
- [ ] Тест на шве `crossCheckDangerousGoods` покрывает: совпадение, расхождение,
      контейнер с 3+ позициями, отсутствующий заголовок, контейнер не найден в сводном
