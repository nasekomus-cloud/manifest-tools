## Что из этого явно ручной ввод (по брифу)

- **CALL SIGN** — «Тебе взять неоткуда» → поле для ручного ввода.
- **ARRIVAL DATE** (и, судя по всему, повторяющаяся внизу «ВЫГРУЗКА <дата>» — та же дата) — «Тебе взять неоткуда» → поле для ручного ввода.

## Что, похоже, берётся из манифеста

- **VESSEL** — в примере манифеста есть строка `Список на погрузку т/х GUANG QI DE ER TA` (ячейка C3 листа `Manifest`) — совпадает с VESSEL в эталоне дословно.
- **VOYAGE** — в примере манифеста есть `Рейс №2601W` (ячейка J3) — совпадает с VOYAGE в эталоне.
- **Разбивка по типам контейнеров и веса** — колонка «Футность» (20DC/40HC/20TK/40FR/45HC) и обе колонки веса («Веc груза», «Веc тары») из манифеста; подсчёт — тот же приём, что уже есть в `lib/port-breakdown.js` (уникальные контейнеры, строка без номера контейнера — не данные, суммирование веса по строкам).
- **Feeder Bill of Lading — N sets** — похоже на количество уникальных коносаментов (тот же приём, что `uniqueBillsOfLading` в `merge/core.js`).

## Что не очевидно (см. брифинг)

- **TERMINAL** — в манифесте нет колонки с терминалом выгрузки (там разные порты назначения на разных строках: `KALININGRAD (RUKGD)`, `St.Petersburg, Timber Port (RUPLP)`), не подтверждено, откуда его брать.
