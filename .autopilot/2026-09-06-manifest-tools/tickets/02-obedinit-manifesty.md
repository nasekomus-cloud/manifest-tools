## Что должно заработать

Жена заходит на `merge/index.html`, перетаскивает или выбирает через кнопку
несколько файлов манифестов, видит список добавленных файлов (может убрать любой,
может перетащить, чтобы поменять порядок — по умолчанию порядок такой, в каком
файлы были добавлены). Кнопка «Объединить» неактивна, пока не выбран хотя бы один
файл.

По нажатию: сначала структура всех файлов проверяется через
`lib/manifest-format.js#validateStructure` — при расхождении показывается понятная
ошибка на русском с именем файла и что именно не совпало, объединение не
выполняется. Если всё совпало — файлы склеиваются в один: значения и полный стиль
ячейки (шрифт, заливка, границы, формат чисел, выравнивание) копируются построчно
из исходников, шапка и ширины колонок берутся из первого файла в списке. Есть
чекбокс «сквозная нумерация №п/п» (по умолчанию выключен) — если включить, колонка
A пересчитывается от 1 до N по всему своду; если выключен — нумерация остаётся как
в исходных файлах (повторяется по разделам).

После объединения на странице сразу видна сводка — какой файл дал сколько строк, и
итоговая сумма — и появляется кнопка «Скачать», отдающая результат как `.xlsx`.

Файл, который не читается как манифест (повреждён, не `.xlsx`, нет листа
`Manifest`), даёт понятную ошибку с именем файла, а не падение страницы.

## Из брифа, дословно

> «Сделай из итих файлов один общий файл. форматы и выделения ячеек сохраняй»
> «Собрал их в один файл в порядке: CNQTAO → EGEDK → NICT → NNBO → PK → Shanghai
> ... Для каждой строки скопированы значения и полный стиль (шрифт, заливка, рамки,
> формат чисел, выравнивание) из исходной ячейки, шапка и ширины столбцов взяты из
> первого файла.»
> «колонку «№п/п» я не пересчитывал — оставил как есть в каждом файле ... Если нужна
> сквозная нумерация по всему своду — скажите, пересчитаю»
> «`--order` — задать порядок файлов вручную вместо алфавитного»
> «Логирование — сколько строк взято из каждого файла»

## Критерии приёмки

- [ ] Можно добавить несколько файлов и перетаскиванием, и через выбор файлов
- [ ] Список файлов позволяет убрать файл и сменить порядок; порядок по умолчанию —
      порядок добавления
- [ ] Кнопка «Объединить» задизейблена, пока файлов нет
- [ ] Файлы с разной структурой (`C5:Y5` не совпадает) дают явную ошибку с именем
      файла и адресом ячейки, результат не создаётся
- [ ] Результат сохраняет стиль ячеек исходников (шрифт/заливка/рамки/формат чисел),
      шапку и ширины колонок из первого файла
- [ ] Выключенный чекбокс «сквозная нумерация» оставляет №п/п как в исходниках;
      включённый — пересчитывает 1..N по всему файлу
- [ ] После объединения видна сводка «файл → строк» и общий итог, ещё до скачивания
- [ ] Кнопка «Скачать» отдаёт корректный `.xlsx`, открывающийся в Excel
- [ ] Испорченный/нечитаемый файл даёт сообщение с его именем, а не падение страницы
- [ ] Тест на шве `mergeManifests` покрывает: обычное слияние, выключенную и
      включённую нумерацию, и отказ при несовпадающей структуре
